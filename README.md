PowerEdit

PowerEdit is a lightweight desktop rich-text editor built with Python and Tkinter, inspired by the classic WordPad experience.

It provides essential document editing and formatting features while keeping the application simple and dependency-light.

Features
Rich-text formatting
Font family and size
Bold, italic, underline, strikethrough
Text color
Left, center, and right alignment
TXT and basic RTF support
New, Open, Save, and Save As
Find and Replace
Undo and Redo
Cut, Copy, Paste, and Select All
Printing
Keyboard shortcuts
Two-row toolbar
Simple color palette
Persistent formatting for selected text
Technology
Python 3
Tkinter / ttk
Python standard library
