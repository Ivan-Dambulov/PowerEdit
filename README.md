# PowerEdit
<img width="463" height="271" alt="image" src="https://github.com/user-attachments/assets/95421b01-f039-441e-8016-9bbd48eb6964" />

A clean, modern rich-text editor built with Python and Tkinter.

PowerEdit gives you the essential writing tools without the bloat.  
Think of it as a lightweight WordPad — with better looks and useful extras.

### Features
- Font, size, color, bold, italic, underline & strikethrough
- Text alignment and lists (bulleted & numbered)
- Insert images with resize
- Create clean graphical tables
- Find & Replace
- Export to PDF (preserves formatting)
- Cross-platform printing (Windows, macOS, Linux)
- Save as RTF or plain text
- Keyboard shortcuts

### Why PowerEdit?
Simple. Fast. Focused.  
No complicated ribbons. No unnecessary features. Just a pleasant place to write and format text.
